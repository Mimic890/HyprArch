Installation by one command

Copy and paste into the terminal:

                git clone --depth=1 -b main https://github.com/Mimic890/HyprArch.git ~/HyprArch && cd ~/HyprArch && [ -f Install.sh ] && chmod +x Install.sh && ./Install.sh

What does the installer do?

After running the command, the installation of HyprArch will begin. The installation takes place in interactive mode, step by step:

  1. Checking your internet connection
    The script will check the Internet connection. If there is no connection, it will ask you to connect to the Internet. If NetworkManager is installed, it will open nmtui for quick connection in the same terminal window.
  2. Assigning execution rights to scripts
    Makes all scripts in the repository folders executable if they were not executable originally.
  3. sudo password prompt
    Requires the user's sudo password to install packages and move files outside the user's directory.
  4. Proposal to add the multilib repository
    It will ask whether to add the multilib repository (it is recommended to agree to add it).
  5. System update
  6. Creating a backup of the current system
    Creating a backup of the current system (recommended) (all backups are stored in the ~/.config/hyprarch/backups/ folder)
  7. Installing the necessary packages
    Installing basic packages, installing yay, and installing basic packages from yay. And checking that all packages were installed successfully or writing down which packages were not installed.
  8. Screen resolution settings
    Run the script that configures the resolution of the main screen (future updates will include full configuration of all monitors and their positions). It will display all detected screens and ask you to select one from the list, which will be set as the main screen in hyprland and other programs.
  9. Creating standard directories
    Creating basic directories in the user directory (Video, Downloads, Documents, etc.)
  10. Choosing the main shell
    When selecting the main shell in the terminal, you will be offered a choice between: fish, zsh, bash, or no change, remaining with the shell that was originally selected.
  11. Configuring system services
    Includes services such as sddm, bluetooth, and others.
  12. Installing and configuring themes
    GTK themes, Qt, icons, and more.
  13. Selecting a theme for Waybar, Rofi, and Nwg-dock-hyprland
    Selecting the theme waybar (configuring the network interface to display speed on the bar), nwg-dock-hyprland, and rofi
  14. Copying configurations
    Copying the configurations selected in the previous step and the configurations for hyprland, waypaper, btop, cava, ...
  15. Configuring SDDM and GRUB
    Configuring the theme and configurations of sddm and grub
  16. Определение видеокарты
    Identify your video card as AMD, NVIDIA, or Intel Arc, and confirm that you have a video card (you can select your video card option).
  17. Wallpaper installation
    Basic set: 10–20. Full set: 50+.
  18. Selecting a text editor in the terminal
    Configuring the text editor in the terminal, you will have a choice: nano, vim, nvim (with my customization, astronvim customization, or without customization)
  19. Installing additional programs
    Choice of additional programs to install (vs code, motrix, gimp, etc.) in the TUI interface If you choose to install Visual Studio Code, after installing all the programs, you will be offered to install my custom HyprVSCode (optional).
  20. Adding the BlackArch repository (optional)
    The question of adding the BlackArch repository (optional) (not recommended for regular users) will appear. If you agree to add it, the same TUI interface will appear, in which you can select the BlackArch categories to install with a brief description (it is recommended to skip the installation and install all BlackArch utilities manually).
