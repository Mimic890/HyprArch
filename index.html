What is HyprArch?

HyprArch is a lightweight Linux distribution based on Arch Linux. It combines the power of the Hyprland window manager with a minimal set of essential tools, offering a clean, fast, and modern desktop. Everything is preconfigured, so you can start using Hyprland instantly.
